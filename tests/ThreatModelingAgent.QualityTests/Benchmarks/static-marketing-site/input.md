# Static Marketing Site

A static marketing website is hosted on Azure Static Web Apps.

There is no login or user authentication.

There is no database.

There is no file upload.

There is no payment processing.

There is no admin panel.

There is no API.

There is no user-generated content.

The site is built from a Git repository using a CI/CD pipeline and deployed automatically on push to main.

Third-party JavaScript analytics are loaded from a CDN.
